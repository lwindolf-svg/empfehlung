| Datei | Wofür |
|---|---|

hier liegt nur die veröffentlichte Kopie. Änderungen dort machen, dann herüberkopieren.

⚠️ Das Auswertungs-Dashboard (`apps/empfehlungs-auswertung/`) gehört **niemals** hierher —
es zeigt Kundennamen und Rückmeldungen.
